# 🎵 Music Stream App

A full-stack music streaming application built with the MERN Stack. This project allows users to browse and stream music while providing an admin panel for managing songs and albums.

## 🚀 Features

- User Authentication
- Music Management
- Album Management
- Audio File Upload
- Image Upload
- REST API
- MongoDB Database
- JWT Authentication
- Secure Routes

## 🛠️ Tech Stack

### Frontend
- React.js
- Tailwind CSS
- Axios

### Backend
- Node.js
- Express.js
- MongoDB
- Mongoose
- JWT
- Multer
- Cloudinary/ImageKit (whichever you're using)
