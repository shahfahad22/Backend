# Notes CRUD API (MongoDB + Express)

A simple REST API built with Express.js and MongoDB that allows users to create, read, update, and delete notes.

## Features

* Create Notes
* Get All Notes
* Update Note Description
* Delete Notes
* MongoDB Database Integration
* RESTful API Structure

## Technologies Used

* Node.js
* Express.js
* MongoDB
* Mongoose
* Dotenv


## Testing Tools

You can test the API using:

* Postman
* Thunder Client
* Insomnia
