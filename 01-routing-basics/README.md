# Express.js Routing Basics

A simple backend project built with Node.js and Express.js to learn routing fundamentals.

## Features

* Home Route
* About Route
* Services Route
* Contact Route
* Blog Route
* Modular Routing using Express Router

## Project Structure

```
01-routing-basics/
│
├── index.js
│
└── routes/
    ├── home.js
    ├── about.js
    ├── services.js
    ├── contact.js
    └── blog.js
```

## Installation

Clone the repository:

```bash
git clone https://github.com/shahfahad22/Backend.git
```

Move into the project folder:

```bash
cd 01-routing-basics
```

Install dependencies:

```bash
npm install
```

Start the server:

```bash
node index.js
```

## Available Routes

| Route     | Description   |
| --------- | ------------- |
| /         | Home Page     |
| /about    | About Page    |
| /services | Services Page |
| /contact  | Contact Page  |
| /blog     | Blog Page     |
